# 邻伴 Web MVP

年轻人上门陪伴匹配产品的可运行演示：家属/老人发单，年轻人接单并完成服务，最后简单评价。

## 运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000 ，选择演示账号进入。

生产构建：`npm run build && npm start`
